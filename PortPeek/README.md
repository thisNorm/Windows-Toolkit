# PortPeek

Windows에서 사용 중인 포트와 프로그램을 한눈에 확인하는 도구입니다.
설치나 관리자 권한 없이 `bin/PortPeek.exe`를 실행하세요.
상위 Windows-Toolkit 폴더의 PortPeek 바로가기로도 열 수 있습니다.

## 트레이에서 빠른 확인

시계 옆 P 아이콘을 한 번 누르면 작은 검색 창이 열립니다. 포트·프로그램·PID를 검색하고 행을 눌러 포트 번호를 복사할 수 있습니다.
TCP 행을 두 번 누르면 브라우저로 엽니다. **전체 목록**을 누르거나 트레이 아이콘을 두 번 누르면 큰 목록을 엽니다.
작은 목록에서도 우클릭 메뉴로 브라우저 열기·포트 복사·확인 후 프로세스 종료를 사용할 수 있습니다.
트레이 아이콘이 숨겨져 있으면 작업표시줄의 `^` 안에서 찾아 밖으로 끌어내세요.
큰 창의 X나 최소화는 트레이에 계속 실행합니다. 완전히 끝내려면 트레이 우클릭 메뉴의 **종료**를 누르세요.
트레이 우클릭의 **Windows 시작 시 실행**으로 자동 실행을 켜거나 끕니다. 체크 표시는 현재 등록 상태입니다.
Windows 로그인으로 실행될 때에는 큰 창을 띄우지 않고 트레이에서 시작합니다.
설정은 현재 사용자 `HKCU/Software/Microsoft/Windows/CurrentVersion/Run/PortPeek` 값만 사용하며, 기본적으로 자동 실행을 등록하지 않습니다.
실행 파일을 이동했다면 새 위치에서 옵션을 다시 켜주세요.

## 목록

- 포트 번호, 프로그램, PID, TCP/UDP, 바인딩 주소 순으로 표시합니다.
- 서버가 대기 중인 TCP 포트와 사용 중인 UDP 바인딩을 보여줍니다. 외부 연결마다 생기는 TCP 클라이언트 포트는 제외합니다.
- 같은 포트·프로그램·프로토콜의 IPv4/IPv6 주소는 한 줄로 묶습니다.
- 검색창에서 포트·프로그램·PID·주소를 검색하고 **전체 / TCP / UDP** 버튼으로 즉시 필터링합니다.
- 열 제목을 누르면 해당 열을 정렬합니다. 포트와 PID는 숫자 순서로 정렬합니다.
- 3초마다 자동 갱신하며 선택한 항목과 스크롤 위치를 유지합니다.

## 즐겨찾기

- 포트 번호 앞의 `☆`를 누르면 해당 포트 번호를 즐겨찾기합니다.
- 프로그램명 앞의 `☆`를 누르면 그 프로그램이 사용하는 모든 포트를 즐겨찾기합니다. PID가 바뀌거나 다른 포트를 사용해도 적용됩니다.
- 선택한 별은 `★`로 바뀌고, 해당 행은 전체 창과 트레이 목록 모두에서 일반 항목보다 위에 표시됩니다. 별을 다시 누르면 해제합니다.
- 즐겨찾기는 검색·TCP/UDP 필터 안에서 우선 표시되며, 각 그룹 안에서는 선택한 열의 정렬을 유지합니다.
- 설정은 `%LOCALAPPDATA%/WindowsToolkit/PortPeek/favorites.txt`에 저장되어 다시 실행해도 유지됩니다. 현재 사용 중이지 않은 포트는 목록에 추가하지 않습니다.
- 목록에서 별 칸을 선택한 뒤 `Enter` 또는 `Space`로도 변경할 수 있습니다.

## 테마

전체 창 오른쪽 위의 **Theme** 버튼 또는 트레이 우클릭의 **테마**에서 **Light / Dark / System**을 선택합니다.
기본값은 System이며 Windows의 앱 테마를 따릅니다. System 모드에서는 Windows 테마가 바뀌면 실행 중에도 반영됩니다.
선택은 `%LOCALAPPDATA%/WindowsToolkit/PortPeek/theme.txt`에 저장됩니다. 전체 창·트레이 빠른 확인·우클릭 메뉴가 함께 바뀝니다.

## 동작

- TCP 항목을 두 번 누르거나 **브라우저 열기**를 누르면 해당 주소를 HTTP로 엽니다. 443/8443은 HTTPS로 엽니다. 모든 TCP 포트가 웹 서버인 것은 아닙니다.
- **포트 복사**는 선택한 포트 번호만 복사합니다.
- **프로세스 종료**는 확인 후 선택한 프로세스에 종료를 요청합니다. 그 프로세스가 사용하는 다른 포트도 닫힙니다.
- 시스템·자기 자신·생성 시각을 확인할 수 없는 프로세스의 종료는 제한합니다. 실행 직전에 PID와 생성 시각, 현재 포트 소유자를 다시 확인하고 같은 프로세스 핸들로 종료합니다.
- 접근 권한이 없으면 오류를 표시합니다. 관리자 권한으로 자동 재실행하지 않습니다.
- 트레이의 P 아이콘은 빠른 확인, 아이콘 두 번 클릭이나 바로가기는 전체 목록을 엽니다.

단축키: `Ctrl+F` 검색, `F5` 새로 고침, `Esc` 검색어 비우기, `Ctrl+Space` 빠른 확인. 목록에서 `Ctrl+C` 포트 복사, `Enter` 브라우저 열기.

## 빌드와 검증

Windows 10/11, .NET Framework 4.8 이상. 외부 패키지는 없습니다.

```powershell
.\build.ps1
.\test.ps1
```

PowerShell 스크립트 실행이 제한되어 있으면 `build.cmd` / `test.cmd`를 실행하세요.
테스트는 테스트 프로세스 소유의 임시 로컬 TCP/UDP 포트를 열어 실제 조회 결과를 확인합니다.
종료 검증은 테스트가 직접 만든 임시 리스너 프로세스만 대상으로 수행합니다. 기존 사용자 프로세스를 종료하지 않습니다.

네트워크 조회는 Windows IP Helper API를 사용합니다. 외부로 목록을 보내지 않으며 방화벽·서비스·네트워크 설정을 바꾸지 않습니다.
